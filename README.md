## Querython Insights Dashboard

### Querython is a competition held at Technical Hub pvt.Ltd for selecting students based on their SQL query knowledge to write the certification of Oracle SQL foundations Associate. To know the insights of this competition this POWER BI Dashboard helps understand how many students from which technologies and branches are qualified at each round.
